ПЕРЕКУП ТЕЛЕФОНОВ — ОБНОВЛЕНИЕ 3.0
1. Загрузите содержимое архива в репозиторий GitHub, заменив www/index.html и сохранив остальные файлы проекта.
2. Сохраните .github/workflows/android.yml.
3. Откройте Actions и запустите Build Android APK.
4. Скачайте APK из Artifacts.

В версии 3.0 добавлен главный экран в стиле смартфона, приложения Агито/Мой банк/Поездки/Сон/Мои телефоны/Мой магазин, выбор из 50 городов, поездки на машине/поезде/самолёте, кредиты и сон с переходом игрового дня.
Прогресс игры сохраняется локально на устройстве.
