ОБНОВЛЕНИЕ ЧЕРЕЗ МОБИЛЬНЫЙ GITHUB:
1. В корне репозитория замени www/index.html этим файлом.
2. Проверь package.json, capacitor.config.json и .github/workflows/android.yml.
3. Commit changes.
4. Открой Actions → Build Android APK → Run workflow.
5. Открой успешный запуск и скачай artifact perekup-telefonov-v2-apk.
6. Распакуй архив и установи app-debug.apk.
